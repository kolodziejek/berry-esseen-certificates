## Reproduction (Python3.12, standard library only)

Run from this directory. Never use -O/-OO. Choose fresh output paths outside
this immutable package:

```sh
python3 -I -B portable.py verify
python3 -I -B portable.py controls --out ../BN39-controls-new
python3 -I -B portable.py smoke --out ../BN39-smoke-new
python3 -I -B portable.py replay --out ../BN39-full-replay-new
```

The full command freshly executes all1126leaves. The smoke only checks the
small complete baseline k3 root. Controls check a genuine Taylor leaf and26
rejections, including unsupported methods, missing children, changed domains,
corrupt coefficients and invalid Gaussian curvature domains. Discovery used
NumPy/SciPy; neither the reader nor reproduction commands need them. Separate
replay uses the same reviewed implementation; it is not an independent full
software derivation.
