# Building this research note

Run `pdflatex -no-shell-escape main.tex` twice in the extracted source folder,
or use `latexmk -pdf main.tex`. The source bundle includes every TeX input
and uses standard AMS, Latin Modern, microtype, geometry and hyperref packages.
It needs no external data, shell escape, network access or certificate program.

This note continues the fixed-target companion in
`mathematics/strategy-v4/2026-10-27/` of the author's fork. It states explicitly
which earlier contact, conservation and Fourier results it uses. Successful
typesetting does not validate those premises or establish the sharp conjecture.
