# Build the research note

Run `pdflatex -no-shell-escape -interaction=nonstopmode -halt-on-error main.tex` twice (three times if references change). The source archive contains every input file. No bibliography, external image, Python program or certificate execution is required to typeset it.

The note proves new moment, phase and gap arguments and reports conditional scalar acquisition. Its successful compilation is not mathematical acceptance of the retained Fourier/contact/support premises or the full Berry--Esseen theorem.
